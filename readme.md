# League of Namur
A turn-based strategy for 2 players, played perfectly in a terminal!

Have you ever wanted to play an rpg board game in your command prompt? Well, now you can!
With this exceptional game you can compete against another player in trying to spend the most time in the center of the map!

## What is it about?
Each player has 4 heroes. Each hero has a class. Each class has different abilities and some have special stats.
Each player's heroes start in their respective spawn points, with some monsters here and there around the map. The goal - spend a certain amount of turns on the special **spur** area of the map. If one of the players' heroes spends enough time there, they win the game. Plain and simple.
